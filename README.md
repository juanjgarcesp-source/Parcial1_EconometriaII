# Parcial 1 - Econometría II

Modelo de regresión de corte transversal sobre los determinantes del salario
de jugadores de la NBA (base `nbasal` del paquete `wooldridge`).

## Contenido
- `parcial1_nbasal.R`: script con especificación, descriptivos, estimación MCO,
  tabla ANOVA, pruebas t y F, y verificación de supuestos.

## Cómo correrlo
1. Abrir el script en RStudio.
2. Ejecutarlo de arriba hacia abajo (instala los paquetes necesarios).
